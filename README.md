# foodlog-lite

記録するだけの食事ログPWA。**評価も採点もしません。** データはスマホの中だけに保存されます。

foodlog本体のフォーク。数値・ゲージ・評価をすべて非表示にし、「記録できた」という事実だけをやわらかく返す構成にしたもの（機能の表示/非表示は `app.js` 冒頭の `LITE_CONFIG` に集約）。

## 使い方

1. ブラウザでアプリのURLを開く（iPhoneはSafariで開いて「ホーム画面に追加」推奨）
2. 設定タブでAnthropic APIキーを登録（写真・テキストの読み取りと締めの一言に使用）
3. 食べたもの・飲んだものを写真か一言で記録。飲み物・あめ・つまみ食いも、なんでも1枚 or 一言でOK
4. 好きなタイミングで「🥗 担当栄養士からひとこと」を押すと、記録を見守っている担当栄養士からコメントが届く（何度でも）

## 主なUI

- **タイムライン**：その日の記録が5:00〜25:00の横棒に●で並ぶ。●タップで品名表示・時刻編集。時刻のない記録は「⏱なし」枠へ
- **記録数・連続日数**：「今日 n件 記録できました」と連続記録日数。途切れても「また今日から」＋過去最長の併記のみ（責めない）
- **PFCのめやす**：AIが概算したP（たんぱく質）・F（脂質）・C（糖質）を品目ごと＋日計で表示。あくまで事実の目安で、目標との比較や色分けはしない
- **担当栄養士からひとこと**：いつでも・何度でも押せる。直近1週間の記録や時刻のリズムまで見たうえで、その日の記録にしか書けないコメントが返る。責めない・説教しない・数値も言わない。連続/累計3・7・14・30日の節目はひとこと祝う

### iOS Safari 実機確認項目（リリース前に必ず）

- [ ] **ホーム画面追加で起動**：Safariで開く → 共有 → ホーム画面に追加 → スタンドアロン起動し記録できること
- [ ] **写真アップロードでEXIF時刻が取得できるか**：カメラで撮った写真を📷から選び、品目に撮影時刻が付くこと。
      **HEICで失敗する場合**はフォールバック動作を確認（EXIFが読めない → ファイルのlastModified → 今日を開いていれば現在時刻、の順で採用されること）
- [ ] **7日不使用時のデータ削除リスクの注記**：iOS SafariはITP（Intelligent Tracking Prevention）により、
      **7日間使わなかったサイトのlocalStorageを削除することがある**。ホーム画面追加したPWAは対象外とされるが、
      Safariタブで使い続ける場合はリスクがあるため、利用者には①ホーム画面追加を推奨し、
      ②ときどき設定タブ「データを書き出す（振り返り用）」でバックアップするよう案内すること

## データについて

- 保存先はこの端末のlocalStorage（`mealoglite:` プレフィックス。本体foodlogとはキーを分離済み）
- 画面には出さないが、AI読み取り時の栄養推定値（P/C等）は裏で保存し続ける（後からの振り返り分析用）
- 外部送信はAI読み取り時のAnthropic APIへの通信のみ
